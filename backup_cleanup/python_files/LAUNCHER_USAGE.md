# Launcher Usage

Use `run_pipeline.sh` for a setup-check-run workflow.

Platform launchers are generated by `setup.py`:

- Linux: desktop icon + `~/.local/bin/ai-data-pipeline-launcher`
- Windows: `launchers/windows/AI-Data-Pipeline.bat` and `.ps1`
- iOS: shortcut setup guide at `launchers/ios/IOS_LAUNCHER_SETUP.md`

## Typical Commands

- Health check only:
  - `./run_pipeline.sh --health-only --smoke`
- Strict production check (credentials + deps required):
  - `./run_pipeline.sh --health-only --smoke --strict`
- Full bootstrap then GUI:
  - `./run_pipeline.sh --setup full --smoke`
- Minimal setup then GUI:
  - `./run_pipeline.sh --setup minimal`

## Options

- `--setup [minimal|full]` install dependencies before checks
- `--smoke` run synthetic Phase 1-3 flow
- `--health-only` run checks and exit
- `--strict` fail if credentials/dependencies are missing
- `--no-gui` skip GUI launch after checks
- `--python PATH` use a specific Python executable

## Notes

- The launcher always runs health checks with `--init-folders`.
- If `OPENAI_API_KEY` is missing, strict enhanced formatting falls back to standard formatting.
